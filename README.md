# 🍅 Фокус

**Помодоро-таймер с учётом времени по проектам.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/focus-timer/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Фокус, короткий и длинный перерыв с автоматическим чередованием
- Точный таймер по отметкам времени — не сбивается в фоновой вкладке
- Звук и системное уведомление по окончании
- Проекты и статистика за неделю: столбчатая диаграмма по дням
- Настройки длительности и автозапуска, обратный отсчёт в заголовке вкладки

## Стек

JavaScript, SVG, Notifications API, Web Audio API. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/focus-timer.git
cd focus-timer
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
